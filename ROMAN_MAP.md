# ROMAN_MAP.md – Verbindliche Szenenreihenfolge nach #15

## Zweck

Diese Datei ist **keine sechste Planungsebene**. Sie zeigt den bereits konstruierten Roman in seiner verbindlichen Lesereihenfolge und macht Rhythmus, Informationswechsel und private/äußere Handlung auf einen Blick prüfbar.

Arbeitsregel:

> **Eine Szenenkarte entspricht zunächst einem Kapitel.**

Ausnahme: `01_01_01` ist der Prolog/Cold Open. Daraus ergeben sich aktuell **Prolog + 47 Kapitel**.

Spätere Zusammenlegungen oder Trennungen sind nur aus Rhythmusgründen erlaubt. Sie dürfen keine neue Handlung erfinden und keine gesetzten Informationsgrenzen zwischen Szenen verwischen. Die Szenenkarte bleibt die Storyeinheit.

# Globale Bewegungen in der Lesereihenfolge

## Daniels Grenze
`Regeln schützen → Warten kostet → eng begrenzter Regelbruch → realer Erfolg → institutionelle Reproduktion → Erfolg trotz Fehlbewertung → Selbstbegrenzung → breitere Kollateralkosten → realer Erfolg → bewusster Nicht-Rückbau → Reversal → erneute Nutzung bei vollem Wissen → tödlicher Schuss → Gegenhypothese im Schlussbild`

## Leserwissen / Quellenmystery
`Schuss ohne Kontext → anonyme Quelle ist real informiert → Insiderzugang möglich → Quelle erwartet Daniel → Lena/Berg/Heller als asymmetrische Erklärungen → Daniel war vor Fallbeginn ausgewählt → Auslassungen sind Methode → realer vermeidbarer Schaden möglich → Heller sehr wahrscheinlich Quelle → finale Information trotzdem wahr`

## Staat / Normalisierung
`normale Verfahren → einzelne persönliche Ausnahme → Nicht-Sanktion → neue prospektive Capability → breitere Anwendung → realer Nutzen trotz Kollateralschäden → Rückbau verweigert → problematische Herkunft offengelegt → formalisiert/kontrolliert fortgeführt → normale Option → nächste Generation geht weiter`

## Privatleben
`Jana: familiäre Reibung + kleine Anomalie → persönliche Gefährdung → eigene Schutzentscheidung → eigener Nachhall`

`Mara: funktionierende Beziehung mit offener Zukunft → reale externe Frist → Daniel verliert gemeinsamen Entscheidungsprozess → Mara entscheidet selbst → Fernbeziehung / neuer Alltag ohne Rücksetzung`

# Rhythmus-Leitplanken nach #15

- Baustein 02 bleibt bewusst kurz und konkret; keine Ausweitung der Normalwelt in zusätzliche Exposition.
- 05.04 bleibt zweigeteilt: Erfolg muss zunächst wirklich wirken, bevor der Riss kommt.
- 06.03–06.04 hält Fehlzuordnung **und** realen Nutzen getrennt, damit das Empathie-Reversal nicht zur didaktischen Widerlegung der Sicherheitslogik wird.
- 07.01–07.03 sind erkenntnisintensiv und dürfen in Prosa nicht zu drei langen Erklärsitzungen werden. Kurze Kapitel, konkrete Beweisschritte, Leerläufe und Hellers Lokalisierung halten Bewegung. Keine zusätzliche Theorie-Szene.
- 08.03 → 08.04 bleibt ohne Verarbeitungspause; nach dem Schuss läuft die Gefahr weiter.
- `08_04_02` ist ein kurzer persönlicher Nachhall, kein zweites Finale.
- 09.01.02 mit Mara ist die letzte private Ruhe vor dem institutionellen Schlussdoppel 09.02/09.03.
- 09.03 endet vor der Sachentscheidung. Keine Epilog-Erklärung danach.

## Prosa-Regel
Die Kapitelnummern sind Arbeitsnummern. Die **Szenenreihenfolge ist verbindlicher als die Nummerierung**. Wenn beim späteren Schreiben zwei sehr kurze Szenen aus Rhythmusgründen in ein Kapitel gehören, darf dies nur ohne Änderung von Plot, Leserwissen oder Szenenfunktion geschehen.
